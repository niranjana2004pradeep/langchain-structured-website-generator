# 🌐 LangChain Structured Website Generator

An AI-powered website generator that converts natural language descriptions into fully functional, production-ready web pages with cleanly separated **HTML**, **CSS**, and **JavaScript** files.

Built using **LangChain**, **Pydantic**, and **Groq** for high-speed, structured LLM generation.

---

## ✨ Features

- **🎯 Structured LLM Outputs**: Leverages LangChain's `with_structured_output()` and Pydantic models to guarantee predictable, typed outputs without relying on brittle regex or markdown delimiter parsing.
- **⚡ Blazing Fast Generation**: Powered by Groq's high-speed inference engine.
- **🧩 Clean Code Separation**: Automatically parses and exports code into separate files (`index.html`, `style.css`, `script.js`).
- **⚖️ Structured vs. Unstructured Comparison**: Includes both structured (`main.py`) and regex-based unstructured (`unstructured_main.py`) implementations to illustrate reliability differences.
- **🎨 Ready-to-View Samples**: Includes sample generated websites in `generated_website/`.

## 🚀 Getting Started

### Prerequisites

- **Python 3.9+** installed
- A **Groq API Key** (Get one free at [console.groq.com](https://console.groq.com))

### 1. Clone the Repository

```bash
git clone https://github.com/niranjana2004pradeep/langchain-structured-website-generator.git
cd langchain-structured-website-generator
```

### 2. Create and Activate a Virtual Environment

**On Windows (PowerShell):**
```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
```

**On macOS / Linux:**
```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Configure Environment Variables

Copy `.env.example` to `.env`:

```bash
cp .env.example .env
```

Open `.env` and set your credentials:

```env
GROQ_API_KEY=your_groq_api_key_here
GROQ_MODEL=openai/gpt-oss-120b
```

> **Note:** You can use any Groq-supported model that supports function/tool calling (such as `llama-3.3-70b-versatile`, `mixtral-8x7b-32768`, etc.).

## 🛠️ Usage

### Run Structured Generation (Recommended)

Run `main.py` to generate files with Pydantic-enforced schemas:

```bash
python main.py
```

This will invoke the chain and write the output directly to:
- `index.html`
- `style.css`
- `script.js`

To customize the website you want to generate, simply edit the `description` prompt in `main.py`:

```python
result = chain.invoke({
    "description": "Create a sleek portfolio website for a freelance UX designer with dark mode"
})
```

---

### Run Unstructured Generation (Regex Parsing)

To experiment with standard prompt generation and regex extraction:

```bash
python unstructured_main.py
```

## 🔬 Structured vs. Unstructured Output

| Feature | Structured (`main.py`) | Unstructured (`unstructured_main.py`) |
| :--- | :--- | :--- |
| **Parsing Mechanism** | Native JSON Schema / Function Calling via Pydantic | Regular expressions (`re.search`) |
| **Error Proneness** | Extremely Low (Guaranteed schema fulfillment) | High (Prone to missing tokens, backticks, formatting variations) |
| **Maintainability** | Type-safe and easily extensible | Brittle regex patterns that need constant updating |
